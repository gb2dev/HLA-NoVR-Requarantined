# HLA-NoVR: Requarantined
The easiest to use and most flexible NoVR mod for Half-Life: Alyx!

This mod makes the entire game playable, with many VR interactions preserved in some form for a flat screen.

This repository holds the public content such as Lua scripts and packed assets.

Get the mod at https://www.patreon.com/cw/gb2dev

## Controls
Check the ingame options menu.
